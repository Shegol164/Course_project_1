## Описание
Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение генерирует JSON-данные для веб-страниц, формирует отчеты, а также предоставляет другие сервисы, такие как:

- Анализ транзакций за определенный период.

- Генерация отчетов: Формирование отчетов в формате JSON и Excel.
- Формирование отчетов по расходам и доходам.
- Получение актуальных данных о курсах валют и ценах на акции.
- Определение выгодных категорий для повышенного кешбэка.
- Анализ трат по категориям за последние три месяца.
- Интеграция с внешними API: Получение данных о курсах валют и ценах на акции через Open API.
## Структура проекта

Модули
1. data/: Содержит Excel-файлы с транзакциями.

2. src/: Основной пакет с модулями приложения.
- views.py: Главная функция для анализа данных. Анализирует данные с начала месяца по указанную дату.
- services.py: Сервис для определения выгодных категорий повышенного кешбэка.
- reports.py: Функции формирования отчетов по расходам за последние три месяца.
- utils.py: Вспомогательные функции для работы с файлами и данными.
- main.py: Основной модуль для запуска приложения.

3. tests/
- Юнит-тесты для основных функций проекта.
4. .env: Файл для хранения чувствительных данных (например, API-ключей).
5. config.py: Конфигурационные параметры (пути к файлам, API-ключи и т.д.).

## Установка
1. Клонируйте репозиторий https://github.com/Shegol164/Course_project_1.git
2. Установите зависимости poetry install
3. Создайте файл .env на основе .env.example и укажите в нем API-ключи:
API_KEY_EXCHANGE=https://v6.exchangerate-api.com/v6/API_KEY_currency/latest/USD
API_KEY_MARKETSTACK=https://api.marketstack.com/v1/eod?access_key=APY_KEY_stocks&symbols=AAPL

## Тестирование.

- Проект покрыт юнит-тестами Pytest. Чтобы запустить тесты с оценкой покрытия выполните команду: pytest
## Логирование.

- Логирование корректной работы функции и возникающих ошибок реализовано в модулях reports, services, utils, views, main.
